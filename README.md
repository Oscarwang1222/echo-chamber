# 回音壁 (Echo Chamber)

一个互动式教育游戏，让你亲身体验信息茧房的形成与打破。

## 灵感来源

参考自 Nicky Case 的《信任的进化》(The Evolution of Trust)

## 如何运行

1. 直接在浏览器中打开 `index.html`
2. 或者使用本地服务器：
   ```bash
   python3 -m http.server 8080
   ```
   然后访问 http://localhost:8080

## 游戏玩法

- 选择你感兴趣的话题标签
- 阅读信息流中的内容，点击你喜欢的文章
- 观察你的"确信度"、"认知健康度"和"茧房指数"如何变化
- 体验信息茧房如何形成
- 学习如何打破茧房

## 技术栈

- 原生 HTML/CSS/JavaScript
- 无需框架，简洁轻量
